# Capturas do Vetor ERP

Capturadas em 10 de novembro de 2026, a partir da aplicação Next.js executada localmente no Chromium. Banco PostgreSQL isolado, migrações do repositório e dados fictícios: empresa “Vetor Demonstração”, três obras, dois parceiros e três materiais. Nenhum banco de produção foi acessado.

- `cover.png`: início e módulos.
- `01-dashboard.png`: indicadores; os totais financeiros estão zerados porque a base de demonstração não contém lançamentos financeiros.
- `02-cadastros.png`: obras de demonstração.
- `03-estoque.png`: materiais de demonstração.

Imagens reais da interface, preservadas em PNG sem composição ou alteração de conteúdo. A barra do navegador foi mantida para identificar a execução local. O arquivo `project.json` define a apresentação e a ordem das imagens no portfólio.
